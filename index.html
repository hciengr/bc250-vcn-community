Identify one recorded run

For an existing PSP-load failure, collect the firmware hash, exact kernel and patches, boot log, command and raw response. Check whether that run actually submitted a VCN PSP request.

Stop when: the run and its evidence are identified—or a missing input is named. Without a same-request trace, leave the rejecting stage unknown.

Help without opening another rabbit hole

Reproduce a published check, attach a missing artifact, or correct a specific claim with evidence. Read the current handoff first. If someone has already done the work, link their result and preserve their credit.

An AI worker can help organize inputs and run a bounded offline check. Its explanation is not evidence. Missing inputs mean a handoff, not permission to invent a substitute or expand the task. Hardware tests belong with the board owner.
